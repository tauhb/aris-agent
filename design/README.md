# Thiết kế giao diện aris

`canvas/` là bản sao mã nguồn của canvas thiết kế "aris — Phương án giao diện" (33 màn, 7 nhóm, thanh bên dùng chung, thư viện 30 linh vật). Mỗi màn là một file `.dc.html`; `canvas.json` xếp các màn thành trang và bảng.

- Đặc tả từng màn: [docs/tinh-nang-aris.md](../docs/tinh-nang-aris.md), mục 11.
- Màn nào làm ở giai đoạn nào: [docs/ke-hoach-trien-khai.md](../docs/ke-hoach-trien-khai.md).

Canvas trên claude.ai là bản gốc. Khi sửa thiết kế, sửa trên canvas rồi chép lại vào thư mục này để giữ lịch sử phiên bản.
