# Check xem đã làm chưa

Danh sách các ý tưởng và câu hỏi của chủ dự án. Sẽ có một lượt kiểm tra riêng để trả lời từng mục: đã có chưa, nằm ở đâu, nếu chưa thì có nên làm không.

1. Đã có chỗ để nạp skill từ các repo GitHub hay chưa?
   - **Đã có** (GĐ8.1): Tự học › Thư viện skill › nút "Nhập skill" (tab GitHub / Claude Code / Codex / Thư mục). Nhập xong vào Hộp duyệt, duyệt rồi gán cho bot.
2. Aris đã cho phép các Connector đấu nối để các bot sử dụng chưa?
   - **Đã có** (GĐ8.1 phần B): Cài đặt › Kết nối (phạm vi cả đội/phòng/bot, nhập từ Claude Code và Codex). Danh mục connector dựng sẵn và OAuth là GĐ8.5, chưa làm.
